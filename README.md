# AuriCore

Migraine prediction and management app, built at Junction 2025 (hackathon, November 2025).

AuriCore combines a person's health data, weather and calendar to estimate their migraine
risk for the next 24 hours and explain the main factors behind it.

## Who built what

| Part | Tech | Author |
| --- | --- | --- |
| [`frontend/`](./frontend/) | React Native (Expo), Supabase, Stream Chat, OpenWeather | [shayanabbas](https://github.com/shayanabbas) |
| [`backend/`](./backend/) | FastAPI, scikit-learn, XGBoost, LightGBM, Firebase, n8n, Docker | [Chamath Wijerathne](https://github.com/ChamathWijerathne) |

The backend serves an ensemble risk model (logistic regression, random forest, XGBoost and
LightGBM, trained with SMOTE balancing) plus per-user summaries from event history in
Firebase. An n8n workflow (`backend/Migraine Risk Monitor.json`) runs scheduled checks.

> The model is trained on **synthetic data** generated by `backend/generate_synthetic_data.py`.
> It is a hackathon prototype, not a medical device.

## Running it

- Frontend: copy `frontend/.env.example` to `frontend/.env`, fill in your own keys, then
  follow [frontend/README.md](./frontend/README.md).
- Backend: see [backend/README.md](./backend/README.md) (generate data, train, run the API).
